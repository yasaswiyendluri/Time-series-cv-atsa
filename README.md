## Overview

In time series forecasting, standard K-fold cross-validation is traditionally avoided due to temporal dependence between observations. However, Bergmeir, Hyndman & Koo (2018) proved that for **purely autoregressive models**, standard K-fold CV remains asymptotically valid **as long as the model residuals are uncorrelated**. In this project, we reproduce their benchmark simulation and real-world sunspot experiments in R, and evaluate three novel extensions for cases when this uncorrelated error condition breaks down.

## What we did

**Replication of the paper**

| Experiment | Data | Models | Methods compared |
|---|---|---|---|
| **Linear study** | Simulated AR(3), MA(1), seasonal AR(12), length 200 | AR(1)–AR(5) | 5-fold CV, LOOCV, nonDepCV, OOS |
| **Neural network study** | Same three processes | MLP (`nnet`), 5 hidden units | Same four methods |
| **Sunspot study** | Yearly sunspots, 1700–1988 | 1560 MLP settings | CV vs OOS model selection |

Both simulation studies use **1000 Monte Carlo trials**, replicating the paper's benchmark scale.

**Our three extensions**

1. **Pre-whitened CV (PW-CV):** Gap CV removes training rows near test folds to remove temporal dependence. PW-CV keeps every row and filters out the correlation from the errors instead.
2. **Multi-horizon forecasting:** The paper only looks one step ahead (h = 1). We compare 5-fold CV, purged gap CV, PW-CV, rolling-origin and static OOS for h > 1, and direct vs recursive forecasts.
3. **Joint selection score J<sub>λ</sub>:** The paper keeps only models that pass the Ljung–Box test, then picks the lowest CV error. We replace this hard cut-off with a continuous score:  
   **J<sub>λ</sub> = RMSE<sub>CV</sub> × (1 + λ(1 − p<sub>LB</sub>))**

## Main results

**1. CV is valid when model residuals are white noise** (Table 1, linear models, 3 lags, 1000 trials)

| Method | AR(3) MAPAE | MA(1) MAPAE | Seasonal AR(12) MAPAE |
|---|---|---|---|
| **5-fold CV** | **0.093** | 0.091 | 110.1 |
| **LOOCV** | **0.092** | **0.089** | 110.5 |
| **nonDepCV** | 0.279 | 0.245 | 215.1 |
| **OOS** | 0.144 | 0.133 | 115.0 |

MAPAE (Mean Absolute Prediction Accuracy Error) measures distance to true out-of-sample error, so lower is better. On stationary AR and MA processes, 5-fold CV and LOOCV achieve the lowest error. When a 3-lag model is fitted to seasonal AR(12) data, Assumption A3 fails and all methods degrade.

**2. CV and OOS pick similar sunspot models** (Table 2):  
Out of 1560 network settings, 679 pass the Ljung–Box test. The model chosen by CV achieves out-set RMSE **2.558**, and the one chosen by OOS achieves **2.626**.

**3. No method wins at every horizon** (Table 8, sunspots, relative error gap %):

| Method | h = 1 | h = 3 | h = 6 |
|---|---|---|---|
| **5-fold CV** | 11.26 | 10.09 | 8.63 |
| **Purged gap CV** | 11.26 | 10.72 | 78.57 |
| **PW-CV** | **2.28** | **6.82** | **4.88** |
| **Rolling origin** | 12.14 | 9.15 | 11.24 |
| **Static OOS** | 6.50 | 10.02 | **5.85** |

Purged gap CV degrades severely at h = 6 (78.57%) due to excessive training data loss after purging. PW-CV retains all observations and performs competitively.

**4. Continuous Joint Selection J<sub>λ</sub>** (Table 9):  
Setting λ = 0 gives the same model as the Ljung–Box filter (out-set RMSE 2.558). Intermediate penalties λ = 0.1 and 0.25 favor simpler models with higher out-set error (3.843), while λ = 0.5 picks a model with RMSE 2.543.

## How to run the code

**Requirements:** R 4.0 or later with `nnet`, `rmarkdown`, and `knitr`.

```r
install.packages(c("nnet", "rmarkdown", "knitr"))
```

### Option 1: Quick verification (view precomputed results)
All generated tables are stored in `csv/`. Run the summary script:
```r
source("scripts/complete_code.R")
```

### Option 2: Full replication from scratch

1. **Replicate 1000-trial simulation study (Tables 1, 3–8):**
   ```r
   rmarkdown::render("rmd/ATSA_project.Rmd")
   ```
   *Note: Runs full 1000 trials by default. Checkpoint files are saved to `ckpt/` to allow seamless resumption if interrupted.*

2. **Replicate 1560 sunspot grid, J<sub>λ</sub>, and figures (Tables 2, 9, Figures 1–3):**
   ```r
   rmarkdown::render("rmd/analysis.Rmd", output_format = "html_document")
   ```
   *Note: Output plots are exported directly to `images/` and model tables to `csv/`.*

## The CHRONOS-CV app

CHRONOS-CV provides an interactive interface to explore all replication tables and extension studies:

| Tab | Features |
|---|---|
| **Studio** | Interactive visualization of fold splitting and purging for 5-fold CV, LOOCV, gap CV, and OOS |
| **Linear** | Empirical error metrics across AR(3), MA(1), and seasonal AR(12) DGPs |
| **Neural** | Non-linear autoregressive MLP benchmark replication |
| **Sunspots** | Interactive parameter filter across the 1560-architecture neural network grid |
| **Whiteness** | In-fold residual autocorrelation diagnostics and causal pre-whitening demonstration |

| **Joint** | Continuous parameter exploration of the J<sub>λ</sub> criterion |

## Notes and limitations

- **Two implementations of PW-CV and J<sub>λ</sub>:** `rmd/analysis.Rmd` implements the causal error-filtering and Yule–Walker rescaling derivation described in Section 4.1 of the report. `rmd/ATSA_project.Rmd` implements an alternative whitened-series benchmark used for Tables 3, 4, 7, and 8.
- **Empirical scope:** Empirical real-data evaluations are conducted on the annual Sunspots series (1700–1988), consistent with Bergmeir et al. (2018).
- **Coursework context:** This project was developed as academic coursework for DA 3041; the proposed extensions are exploratory heuristics.
